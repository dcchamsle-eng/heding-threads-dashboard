## 2. 브랜드 아이덴티티

- **페르소나:** 쿨한 커리어 파트너 — 전문성 있되 가볍게, 정보 주되 강요 없이
- **미션:** 직장인이 이직을 생각할 때 가장 먼저 떠오르는 파트너
- **타겟:** ① 20~30대 직장인(이직 희망자) ② 기업 HR 담당자
- **금지:** 특정 기업·인물 비방, 정치적 발언, 성별·나이·지역 비하, 미확인 정보 게시

### 브랜드 보이스 4원칙
1. **내부자처럼 말한다** — 가르치지 않고 공유. "협상 안 하고 사인하는 분들 아직도 많아요"
2. **공감이 먼저다** — "맞아, 나 얘기야" 싶어야 읽힌다
3. **강요하지 않는다** — "이직 하실래요? 🙂" 판단은 독자가
4. **채널마다 온도가 다르다** — 같은 사람, 다른 옷

### ⚠️ CI 전환 원칙 (2026-09 기준)
> 리멤버×헤딩 합작으로 **'헤딩써치'** 출범이 공식 보도됨(9/4~9/6, 이투데이·전자신문·블로터 등). 이에 따라 모든 소셜채널의 CI를 **헤딩써치 최신 브랜드**로 통일한다.

## 4. 캐릭터 "헷" (SNS용 캐릭터)

> 헤딩(H≡DING)의 앞 음절. **공식 마스코트 아님 — SNS 헤드헌터 과장님 캐릭터** (회사 공식 결정 부담 회피)

| 항목 | 설정 |
|---|---|
| 이름 | 헷 |
| 직업 | 과장 (헤드헌터) |
| 나이 | 비공개 |
| 외형 | 치비(SD) 스타일, 검은 3피스 수트, 검은 머리, 무표정 |
| 시그니처 아이템 | HEDING 명함 (항상 왼손에) |
| 성격 | 침착·냉철·신뢰감 |
| 별명 | **이직해무새** ("이직을 해야 채용이 생긴다"는 직업적 합리화 셀프디스) |

### 핵심 컨셉 — 갭모에 (Gap Moe)
**겉은 차갑고 냉철, 실제 행동은 귀엽다.** 이 갭이 팔로우하게 만드는 이유.

| 겉모습 | 실제 행동 |
|---|---|
| 무표정, 냉철한 눈빛 | 드라마 포스터에 몰래 합성돼 나타남 |
| 말이 없고 표현 안 함 | 연봉표 열심히 정리해서 들고 옴 |
| 다가가기 어려운 분위기 | 야근 스레드 찾아가 "이직 하실래요?" |

### 캐릭터 사용 원칙
- 무표정 유지, 명함은 HEDING 로고 보이게, 대사는 짧게
- 실제 드라마·영화 컷 합성은 저작권 리스크 → 헷 단독 연출로 전환 권장
- 캐릭터 IP는 헤딩 귀속, 운영자는 협약 기간 중 자유 활용 + 포트폴리오 활용권

### 앵무새 말투 (희소성 규칙)
- **기본은 정상 말투, 가끔(10개 중 1~2개)만 앵무새 말투** — 매번 쓰면 말버릇, 가끔 쓰면 빵 터지는 포인트
- 말투: `~에오 / ~할게오 / ~하실래오` (앵무새라 말끝이 뭉개짐)
  - 예: "안녕하세오, 이직해무새에오 🦜 / 이직도 도와드리고 채용도 도와드려오 / '이직해라'라고 반말은 안 할게오"
- **쓰기 좋은 타이밍:** 텐션 올랐을 때, 셀프디스("또 왔네오, 이직해무새에오"), 댓글 받아칠 때, 진지하게 쓰다 마지막 한 줄만 "…이직하실래오?"
- **안 쓰는 타이밍:** 채용공고 카드, 기업 HR 상대 멘트, 진지한 정보성 게시물 (정보 신뢰도 유지)
- 효과: 평소 무표정 쿨한 헷 ↔ 어눌한 앵무새 말투 = 추가 갭모에. 팔로워가 "오늘은 앵무새 나오나?" 기다리게 됨
- **검증됨:** 실전에서 "이직해무새" 반응 확인 — 직접 권유엔 방어적이지만 셀프디스한 캐릭터엔 무장 해제된다는 데이터

## 8. 댓글 게릴라 멘트집

### 추적 키워드
야근, 퇴사, 퇴사각, 번아웃, 이직, 이직고민, 이직각, 면접, 탈락, 합격, 헤드헌터, 헤드헌팅, 채용공고
> ⚠️ **연봉·팀장·사수 키워드는 예민 주제라 제외** (개인 사정 얽혀 역효과 위험)

### 시그니처 라인
- `보이면 갑니다.`
- `저에게 보이시다니, 이직각인가`
- `어쩌다 저 같은 계정에 보이셔서…` (줄임표로 끝, 뒤에 말 안 붙임)
- `기회 줄 때 글 내리세요.`
- `이직해무새` (별명·해시태그화)
- `자꾸 왔다갔다 하실래요? 🙂` (이직 고민 몇 달째 망설이는 사람 저격)

### 톤 스타일 2종
1. **직접형:** "보이네요. 이직 하실래요? 🙂" / "고민 중이시면 이미 답 나온 거예요."
2. **운명적 관찰형 ("~하셨다니"):** "이 시간에 깨어있으시다니, 퇴사각인가" / "그 회사에 또 떨어지셨다니"

### 칭찬꼬시기 (뭐든 칭찬 후 이직 권유)
- 글·콘텐츠: "글 잘 쓰시네요. 이직하실래요?"
- 능력: "일 잘하시는 거 티 나네요. 이직하실래요?"
- 패션: "패션이 멋지시네요. 이직하실래요?"
- 소품: "커피 잘 고르시네요. 이직하면 새 회사 카페도 알려드릴게요."
> ⚠️ 외모 직접 칭찬("잘생기셨네요")은 지양 — 능력·패션·소품으로 대체

### 운영 원칙
댓글 1줄 / 느낌표 자제 / 이모지 1개 / 적당히 무심하게 / 하루 5~10개 선별

## 11-2. 장기 운영 전략 (잠입 → 2년 빌드업 → 정체 공개)

> 헷 계정은 기존에 반응 좋던 계정(음식 사진, 조회수 천 단위)을 **서서히 헷 계정으로 변신**시키는 방식. 신규 계정이 아니므로 "팔로워 유입"이 아니라 "정체 공개 타이밍"이 관건.

**핵심 원칙: 완전 신비주의 유지, 2년 후 정체 공개**
- 헤딩 연결 단서 완전히 숨김 (프로필 링크·사명 노출 X)
- 음식 사진 = 위장막이자 신뢰 자산. **음식 콘텐츠 계속 유지하며 헷 요소를 하이브리드로 얹기** (급전환 시 언팔 위험)
- "맛집 소개하는 헤드헌터" 자체가 유니크 포지셔닝

**3단계 변신**
1. **잠입 (현재):** 음식 사진 사이 헷 요소 아주 가끔. 캡션에만 채용 뉘앙스 살짝
2. **궁금증 유발:** 헷 멘트·댓글 게릴라 빈도 서서히 ↑. "이 계정 원래 이런 계정 아닌데?" 화제화
3. **정체 공개 (약 2년 후, 한 방):** "사실 저, 헤딩 헷 과장입니다" → 기존 조회수 기반 위에서 터지면 공개 자체가 바이럴

**2년 빌드업 중 할 것**
- 이직해무새를 밈 자산으로 굳히기 (등장 카운트 "D+147", "또 왔습니다 이직해무새" 반복 → 팔로워가 먼저 불러주는 단계)
- "떡밥 로그" 심기: 명함 살짝, "H로 시작하는 회사" 등 미묘한 복선 → 공개 시 "그때 그게 복선이었어?" 역주행 유발
- 반응 데이터 기록 (뭐가 터지고 안 터지는지 로그 → 공개 콘텐츠를 최적 포맷으로 설계)

**검증된 신호:** "이직해무새" 이미 실전에서 반응 터짐 → 셀프디스·갭모에 공식이 통한다는 증거
